# Último Oasis

Juego de gestión y cadena de suministros con estilo visual inspirado en *Frozen City*: sin héroes, una sola zona que se puede completar y que se ampliará en futuras actualizaciones. Escrito en JavaScript (Vite + PixiJS).

El diseño completo (tema, recursos, edificios, balance, dirección de arte, arquitectura y hoja de ruta) está en [`docs/GDD.md`](docs/GDD.md).
